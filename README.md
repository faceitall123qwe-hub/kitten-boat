# kitten-boat

Short animated video for kids: a kitten rows a little boat, meets some ducklings and then we go
under the water with the fish. Made with [Remotion](https://www.remotion.dev/) (React components rendered to
video). The fish, waves and bubbles are drawn in SVG, the stills and sounds come from the `gen-*`
scripts.

```bash
npm install
npm run dev      # Remotion studio
npm run render   # out/kitten-boat.mp4
```
